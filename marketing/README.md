# תיקיית השיווק והנתונים

| תיקייה | מה שמים בה |
|---|---|
| `config/economics.json` | מחירים, עלויות (כרגע לדוגמה בלבד), תמהיל הזמנות, ספי מדדים וכללי החלטה |
| `data/raw/` | קבצי ייצוא כמו שהם: Meta Ads Manager (לפי מודעה ויום), TikTok Ads, Google Ads, הזמנות מהחנות, GA4 |
| `data/processed/` | נתונים אחרי ניקוי ואיחוד |
| `outputs/` | דוחות וניתוחים: `YYYY-MM-DD_<שם>.md`, ולצידם CSV וגרפים |
| `tools/` | סקריפטים. `unit_economics.py` מחשב תקרת עלות לרכישה לכל מארז ולתמהיל |

## איך מייצאים מ-Meta Ads Manager

ברמת המודעה, עם פירוק לפי יום. העמודות החשובות:
- חשיפות וצפיות של 3 שניות.
- הקלקות על קישור והוצאה.
- צפיות בדף נחיתה.
- הוספות לסל ורכישות.
- ערך רכישה ותדירות.

שומרים את הקובץ ב-`data/raw/` ומבקשים מקלוד: "תריץ דוח שבועי".

## עדכון הכלכלה

1. ממלאים ב-`config/economics.json` את העלויות האמיתיות: מוצר, משלוח, אריזה, עמלת סליקה ושיעור ביטולים.
2. מריצים מתיקיית הריפו:

```
python3 marketing/tools/unit_economics.py
```
